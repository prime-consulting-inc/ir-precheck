# わかっている見逃しと誤検知（1.0.0 時点）

## 見逃すもの

- 画像になった文字（スキャンしたPDF、画像で貼った表）。文字として抽出できないため、社外秘の表記もレビュー文言も拾えません。
- 小さな円や半透明の帯、モザイクだけで隠した画像。地図の点やバッジと区別しにくいため、検知の対象にしていません。
- 黒以外の色（濃い灰色、紺など）の図形を重ねただけの黒塗り。
- 年のない日付（「11月20日（木）」）の曜日のずれ。
- 前の期の資料をコピーして残った古い日付・期の表記。`--period` は、指定した決算期が本文にあるかを見るだけです。
- Acrobatで上書き保存したPDFに残る、以前に保存した内容（増分保存）。
- Wordのテキストボックス・脚注の中の文字、書式だけの変更履歴。
- Excelの非表示の行・列、外部リンク。
- スライドマスター・レイアウトに残った文字やロゴ。

## 出ることがある誤検知

- 白文字：色付きの帯に白抜きの見出しを置き、帯と文字の間の余白が狭いと、白地の白文字と判定することがあります。6件以上は「情報」にまとめます。
- 本文の「（案）」：「定款変更（案）」のように開示資料に正規に出る場合も要修正になります。
- 作成日時：テンプレートから作ったファイルは、作成日時が開示日より90日以上前と出ることがあります。
- 他社名：取引先として書いた会社名も「情報」に出ます。

誤検知・見逃しを見つけたら Issues で知らせてください。
