# 提出前の目視チェックリスト

`ir_precheck.py` は機械で拾える項目だけを見ます。以下は人の目（作成者とは別の人）が最終確認してください。

## すべての開示資料（PDF化の前後）

- [ ] ブラウザで開き、タブ名（PDFタイトル）に「案」「ドラフト」「チェック依頼」「v8」「clean」「final2」が出ていない
- [ ] 文書のプロパティ（タイトル・作成者・サブタイトル・キーワード）が空、または「自社名＋開示表題」になっている。個人名、他社名、パートナー名がない
- [ ] TDnetのプロパティ確認画面を音読してから OK を押す
- [ ] 印刷・検索・コピー禁止、パスワードをかけていない
- [ ] 自社名・証券コード・文書日付・決算期・ページ番号が正しい
- [ ] 前年・前四半期・他社テンプレを流用した場合、古い期・他社名・他社コードが残っていない
- [ ] 「議案」など通常用語と間違えやすい箇所を除き、「（案）」が本文に残っていない
- [ ] 黒塗りがある場合は Acrobat の「墨消し」を適用済み。全選択してメモ帳に貼り、伏せた語が出ない
- [ ] グラフの「A社」「B社」などの伏せ表記を、全文コピーしてメモ帳に貼り、実名が残っていないか確かめる。ぼかしや白い文字、画像の重ねだけになっていないか見る
- [ ] 画像の切り抜きはマスクではなくトリミングまたは画像化。はみ出しや裏の文字がない
- [ ] 承認用透かし（「開示委員会資料」「社内限り」「社外秘」「Confidential」）が本番ファイルに残っていない
- [ ] 付箋、「統一する」「要確認」「差し替えてください」など、社内向けの指示が残っていない
- [ ] 図形や別画像で隠したつもりになっている箇所で、下の元画像が残っていない（小さな円での隠しや半透明の帯は機械では保証しない）
- [ ] プロパティの作成日時・更新日時が、開示日と大きくずれていない。複数本を出すときは作成順が開示順と矛盾しない
- [ ] 自社サイトへの掲載は TDnet 開示確認後。予約投稿・非公開ステータスを過信しない

## 決算説明会資料・成長可能性資料（PowerPoint由来）

- [ ] 公開用は「ノートなし」で書き出している。ノート付き版を出すなら、その旨を明示し、社内メモや未公表数値がノートにないことを確認する（ノート付きを正規公開している会社もある）
- [ ] 非表示スライド、隠しスライドを削除してから書き出している
- [ ] スライドマスターに他社ロゴ、旧ロゴ、他案件のフッターが残っていない
- [ ] グラフの値ラベル・棒の高さ・円グラフの構成比が、同じスライドの表および決算短信と一致する
- [ ] 縦軸の起点・単位・スケールが誤解を招かない（ゼロ以外から始まる場合は注記がある）
- [ ] グラフがスライド枠を突き抜けていない
- [ ] 前期資料や中期計画からコピーした数字が、今回の定義・時点と一致している（前年比の比較対象期を間違えていない）
- [ ] 短信は百万円、説明資料は億円など、単位換算が正しい
- [ ] 目次のページ番号が最終版と一致している
- [ ] 英語版がある場合、日本語版と数値・期・社名が一致している
- [ ] 動画を出す場合、限定公開の設定を二人で確認し、短信開示前に一般公開していない

## 訂正が必要になったとき

- [ ] 原則として差し替え・削除はせず、「適時開示資料の訂正」として正誤表を出す
- [ ] 表題の冒頭に「（訂正）」（XBRLも直すなら「（訂正・数値データ訂正）」）
- [ ] 説明会資料を直す場合、ノート付き版・動画・補足資料も同時に直すか確認する
